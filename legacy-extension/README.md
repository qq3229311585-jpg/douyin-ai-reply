# 抖音评论 AI 怼

在抖音网页版（douyin.com）评论区，每条评论旁悬浮一个「AI 怼」按钮。点击后调用 Anthropic API 生成 3 条回复，你点选一条，它会填入评论回复框。**不会自动发送**，发不发、怎么改都由你决定。

## 安装

1. 打开 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹

## 设置

扩展详情页 → 扩展程序选项，填写：

- **Anthropic API Key**：只保存在本机浏览器中
- **模型**：可修改
- **接口地址**：仅在使用代理时修改

## 用法

1. 鼠标悬停在某条评论上，右上角出现「AI 怼」
2. 选择风格，可选填写你的立场
3. 点「生成」
4. 点选一条回复，即填入回复框

## 已知限制

- 只支持 douyin.com 网页版
- 只处理顶层评论，不含子回复
- 抖音网页改版后可能失效，需要适配代码
