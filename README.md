# 抖音评论 AI 怼

一个油猴(Tampermonkey)脚本:在抖音网页版评论区里,把鼠标停在某条发言上,出现「AI 怼」按钮。点开后,AI 会通读整楼对话和视频信息,站在你这边写出 3 条回复,点一条就填进回复框。**只填不发**,发不发由你决定。

## 它能做什么

- **点哪条回哪条**:鼠标停在楼里的哪一条发言上,就回应那一条;AI 依然读完整楼,知道前因后果和你想表达的意思。
- **读得懂上下文**:整楼对话按顺序编号,谁回复谁、谁是视频作者、哪句是你说的(在设置里填抖音昵称即可),都会告诉 AI。
- **懂这个视频在讲什么**:视频文案、话题、作者,以及抖音自己的 AI 内容总结和分章节要点。
- **能看图、懂表情**:评论里的图片会缩小后发给 DeepSeek 识别(最多 4 张),`[泪奔]` 这类表情也会按含义理解。
- **四种风格**:狠辣毒舌、阴阳怪气、幽默调侃、以理服人。每条回复都要有理有据,不是纯骂;「以理服人」不会写成嘲讽。
- **帮你查错**:你前面说过的话如果有事实错误或容易被抓漏洞,会在提醒里告诉你,也会顺带补充相关知识。
- **需要时才联网**:模型自己判断要不要搜索,知道的不搜,省钱;可在油猴菜单里整体关闭。
- **流式输出**:字一个个出来;出完后按数字键 1/2/3 直接选回复,Esc 关闭面板。

## 安装

1. Chrome 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [脚本原始文件](https://raw.githubusercontent.com/qq3229311585-jpg/douyin-ai-reply/main/douyin-ai-reply.user.js),油猴会弹出安装页,点「安装」。
3. 打开 douyin.com,把鼠标停在任意评论上,点「AI 怼」。第一次使用会让你填 API Key(以及可选的自己的抖音昵称)。

升级时同样打开原始文件地址,点「更新」,再刷新抖音页面。

## 设置

- API Key 只保存在你本机的油猴里,不在代码里,也不会上传到任何地方(除了你配置的模型接口)。
- 默认使用 DeepSeek(`https://api.deepseek.com`,模型 `deepseek-flash`)。**只有 `deepseek-flash` 能看图**,换成别的模型会自动变成纯文字。
- 接口地址含 `anthropic.com` 时,自动按 Claude 的格式调用(也支持看图,但没有联网搜索)。
- 模型、接口地址、联网搜索开关,都在油猴图标的菜单里改。

## 使用须知

- 评论里的「展开 N 条回复」需要你**自己手动点开**。没展开的回复 AI 看不到,脚本会明确告诉它这一点,不会让它假装读过。(脚本不做自动点击,以免触发抖音的风控验证。)
- AI 看不到视频画面和声音,只能看到文字信息和评论里的图片。
- 视频详情用的是抖音网页自己的同源接口,不是官方公开接口,以后可能失效;失效时只会少一些视频背景,其余功能照常。
- 图片需要从抖音图片服务器取回,取不到的图会如实告诉 AI「没能加载」。
- 请遵守平台规则和法律,文明发言。脚本已要求 AI 不骂脏话、不攻击地域、性别、外貌、家人等身份特征,但发出去的话由你自己负责。

## 界面

默认界面是近黑底、单一蓝色强调、等宽字体的「现代终端」风格。

`ui-options/` 里是其他备选界面的预览页,用浏览器直接打开就能看:

| 文件 | 内容 |
| --- | --- |
| `01-terminal-newspaper-hardware.html` | 终端 / 报纸 / 硬件各三版(现在用的是第一个) |
| `02-eight-wild-styles.html` | 8 种差异很大的方向:终端、杂志社论、新野兽派、液态玻璃、街机格斗、硬件、经典 Mac、纯排版 |
| `03-neutral-abc.html` | 三版中性灰:shadcn 风、Radix 灰阶、偏终端暖灰 |
| `opus-red-design/` | 最早的红色版本(已弃用) |

想换界面:改脚本里 `st.textContent` 那一大块 CSS,以及 `openPanel` 里的 HTML 模板即可,功能代码不用动。备选版本还没有移植进脚本。

## 目录

- `douyin-ai-reply.user.js`:脚本本体
- `ui-options/`:备选界面预览
- `legacy-extension/`:最早的 Chrome 扩展版本,已不再维护
